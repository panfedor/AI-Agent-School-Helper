**Твой личный ИИ-агент**

*Реализовал комплексного ИИ-агента для сопровождения обучения в «Школе 21». Агент помогает с выбором специализации, анализирует рынок вакансий, составляет персональный учебный план и присылает дайджесты новостей по выбранному профилю.*

**Что сделано и освоено**

- Развернул **n8n** на облачной платформе Cloud.ru с использованием **Docker**.
- Настроил **Telegram-бота** (@BotFather), интегрировал его с **LLM (GigaChat API)** и реализовал память (**SimpleMemory**) для удержания контекста диалога.
- Написал **системные промпты**, превращающие LLM из пассивного ассистента в проактивного агента с целями и планом действий.
- Настроил **парсинг Telegram-каналов через RSS** и агрегацию постов в ежедневные дайджесты с суммаризацией через GigaChat.
- Настроил **парсинг вакансий с hh.ru через API**, реализовал автоматическое выделение топ-15 самых частых требований с помощью AI-агента и нормализацию навыков.
- Реализовал **персонального ментора**: бот задаёт вопрос о желаемой теме, формирует план обучения, ищет материалы через **Tavily Search API** и присылает посты без повторов с сохранением состояния через **Static Data** в n8n.
- Познакомился с **RAG (Retrieval-Augmented Generation)** — создал систему поиска релевантных вакансий на основе анализа резюме и личностного опросника с использованием эмбеддингов **ru-en-RoSBERTa (Hugging Face)** и векторного хранилища **Simple Vector Store**.

**Использованные технологии и инструменты**

- **n8n** — платформа для автоматизации workflow
- **Cloud.ru** — облачная платформа
- **Docker** — контейнеризация
- **GigaChat API** — LLM для генерации ответов и суммаризации
- **Telegram Bot API** — интерфейс для пользователя
- **RSS** — парсинг Telegram-каналов
- **HeadHunter API** — парсинг вакансий
- **Tavily Search API** — поиск информации в интернете
- **Hugging Face API** — эмбеддинги (ru-en-RoSBERTa)
- **Simple Vector Store** — векторное хранилище
- **SimpleMemory / Static Data** — хранение контекста и состояния

**Ключевые навыки, полученные в проекте**

- Работа с LLM через API
- Создание AI-агентов (системные промпты, инструменты, память)
- Развёртывание сервисов в облаке (Docker + Cloud.ru)
- Интеграция Telegram-ботов с внешними API
- Парсинг и агрегация данных из открытых источников
- Анализ вакансий и выделение ключевых требований
- RAG (retrieval augmented generation) — поиск и генерация по документам
- Написание промптов для сложных сценариев поведения
